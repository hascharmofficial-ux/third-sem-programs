# Python Programs

*program1.py* : Demonstrates Python list operations by creating a fruit list, accessing specific indices, and updating elements.
*program2.py* : Accepts 10 user-input integers into a list and calculates their sum and average without using the built-in sum() function.
*program3.py* : Reads a list of space-separated integers and removes duplicate elements while maintaining their original order.
*program4.py* : Finds the smallest and largest integers from a list of 7 user-provided numbers without using min() or max().
*program5.py* : Reverses a list using a two-pointer in-place swapping technique without using reverse() or slice syntax.
*program6.py* : Checks whether a given user-input year is a leap year based on Gregorian calendar rules.
*program7.py* : Calculates the Euclidean distance between two points in 2D space.
*program8.py* : Checks whether three given angles can form a valid triangle based on angle sum property.
*program9.py* : Calculates whether a transaction resulted in profit, loss, or break-even given cost price and selling price.
*program10.py* : Computes simple interest given principal, rate of interest, and time period.
*program11.py* : Calculates the volume of a cylinder using user-supplied radius and height.
*program12.py* : Checks whether an entered integer is divisible by both 3 and 6.
*program13.py* : Evaluates temperature and humidity inputs to classify the weather condition as hot and humid or normal.
*program14.py* : Extracts each digit of a number from right to left and prints its square.
*program15.py* : Checks whether a given integer is an Armstrong number (sum of the cubes of its digits equals the number).
*program16.py* : Checks whether a 4-digit number is a narcissistic number (sum of each digit raised to power 4 equals the number).
*program17.py* : Determines applicable income tax slab based on the user's monthly salary range.
*program18.py* : Provides a menu-driven CLI for unit conversions (cm to inches, km to miles, USD to INR).
*program19.py* : Swaps two integers using a temporary variable.
*program20.py* : Swaps two integers using arithmetic addition and subtraction without a temporary variable.
