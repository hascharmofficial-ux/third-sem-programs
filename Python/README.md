# Python Programs

| File | Program / Topic | Description |
| :--- | :--- | :--- |
| `fruit_list_operations.py` | Program 1 | Demonstrates Python list operations by creating a fruit list, accessing specific indices, and updating elements. |
| `sum_average_without_sum.py` | Program 2 | Accepts 10 user-input integers into a list and calculates their sum and average without using the built-in `sum()` function. |
| `remove_duplicates_ordered.py` | Program 3 | Reads a list of space-separated integers and removes duplicate elements while maintaining their original order. |
| `min_max_without_builtin.py` | Program 4 | Finds the smallest and largest integers from a list of 7 user-provided numbers without using `min()` or `max()`. |
| `reverse_list_in_place.py` | Program 5 | Reverses a list using a two-pointer in-place swapping technique without using `reverse()` or slice syntax. |
| `leap_year_checker.py` | Program 6 | Checks whether a given user-input year is a leap year based on Gregorian calendar rules. |
| `euclidean_distance_2d.py` | Program 7 | Calculates the Euclidean distance between two points in 2D space. |
| `triangle_validity_checker.py` | Program 8 | Checks whether three given angles can form a valid triangle based on angle sum property. |
| `profit_loss_calculator.py` | Program 9 | Calculates whether a transaction resulted in profit, loss, or break-even given cost price and selling price. |
| `simple_interest_calculator.py` | Program 10 | Computes simple interest given principal, rate of interest, and time period. |
| `cylinder_volume_calculator.py` | Program 11 | Calculates the volume of a cylinder using user-supplied radius and height. |
| `divisibility_by_3_and_6.py` | Program 12 | Checks whether an entered integer is divisible by both 3 and 6. |
| `weather_condition_classifier.py` | Program 13 | Evaluates temperature and humidity inputs to classify the weather condition as hot and humid or normal. |
| `digit_squares_reverse.py` | Program 14 | Extracts each digit of a number from right to left and prints its square. |
| `armstrong_number_checker.py` | Program 15 | Checks whether a given integer is an Armstrong number (sum of the cubes of its digits equals the number). |
| `narcissistic_number_checker.py` | Program 16 | Checks whether a 4-digit number is a narcissistic number (sum of each digit raised to power 4 equals the number). |
| `income_tax_calculator.py` | Program 17 | Determines applicable income tax slab based on the user's monthly salary range. |
| `unit_converter_menu.py` | Program 18 | Provides a menu-driven CLI for unit conversions (cm to inches, km to miles, USD to INR). |
| `swap_numbers_with_temp.py` | Program 19 | Swaps two integers using a temporary variable. |
| `swap_numbers_without_temp.py` | Program 20 | Swaps two integers using arithmetic addition and subtraction without a temporary variable. |
| `decorator_show_info.py` | Program 21 | Implements a decorator `show_info` that logs messages before and after executing a function `square(num)`. |
| `decorator_double_result.py` | Program 22 | Implements a decorator `double_result` that doubles the return value of an addition function `add(a, b)`. |
| `generator_countdown.py` | Program 23 | Implements a generator function `countdown(n)` that yields numbers counting down from n to 1. |
| `generator_even_numbers.py` | Program 24 | Implements a generator function `even_numbers(limit)` that yields all even numbers up to a given limit (e.g., 10). |
